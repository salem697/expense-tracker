# Python Expense Tracker

A command-line application built with Python that allows users to record, manage, search, and analyse their daily expenses.

## Features

- **Add Expenses:** Record an expense amount and category.
- **View Expenses:** Display all recorded expenses.
- **Calculate Total:** Calculate the total amount spent.
- **Search Expenses:** Find expenses using their category.
- **Delete Expenses:** Remove unwanted expense records.
- **Monthly Reports:** View expenses recorded in a particular month.
- **Category Reports:** Calculate spending totals for each category.
- **Data Persistence:** Save and load expenses using JSON.
- **Input Validation:** Handle invalid amounts and empty categories.
- **Date Tracking:** Automatically record the date of each expense.

## Technologies Used

- Python 3
- JSON
- Python `datetime` module

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code or another Python editor.
3. Open the terminal.
4. Run:

```bash
python expense_tracker.py
```
